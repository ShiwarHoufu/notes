
# systemd 管理命令

**systemd** 是现在主流 Linux 的系统和服务管理器。
`systemctl` 是 systemd 的管理命令。

> 以下示例以 Nginx 为例：

| 命令                           | 作用                                       |
| ---------------------------- | ---------------------------------------- |
| `systemctl status nginx`     | **查看服务状态**，是否运行、报错日志                     |
| `systemctl start nginx`      | 启动服务                                     |
| `systemctl stop nginx`       | 停止服务                                     |
| `systemctl restart nginx`    | 重启服务（先 stop 再 start）                     |
| `systemctl reload nginx`     | **热加载配置**，不中断服务，重新读取配置（nginx 支持，部分程序不支持） |
| `systemctl enable nginx`     | 设置**开机自动启动**                             |
| `systemctl disable nginx`    | 取消开机自启                                   |
| `systemctl is-active nginx`  | 只查看服务是否正在运行                              |
| `systemctl is-enabled nginx` | 查看是否开机自启                                 |
| `systemctl daemon-reload`    | **修改服务配置文件后必须执行**                        |

# 文件权限命令

> root 用户可用这些命令

Linux 每个文件 / 文件夹都有：**所有者** (owner)、**所属组** (group)、**权限** (rwx)
(每个文件只能有一个所有者，一个所属组)
## 用户组管理
>所有用户组都存在 `/etc/group`

- 添加用户组 `groupadd`
- 删除用户组 `groupdel`
- 修改用户组名称 `groupmod`

**gpasswd**命令
```bash
# 添加用户alice进demo组
gpasswd -a alice demo
# 把用户alice从demo组移除
gpasswd -d alice demo
```

## chown（change owner） 修改文件归属
语法格式：
```bash
chown 用户名:用户组 文件名/目录
```

```bash
# 把 test.txt 的所有者改成 root，所属组也改成 root
chown root:root test.txt

# 只改所有者
chown www-data test.txt
# 只改所属组
chown :www-data test.txt

# -R 递归（文件夹+里面所有文件全部修改）
chown -R www-data:www-data /var/www/html
```
## chmod (change mode) 修改读写执行权限

权限分三类角色：**所有者 u、所属组 g、其他人 o**

权限符号：
- `r` read 读 = 4
- `w` write 写 = 2
- `x` execute 执行 = 1

| 数字        | 权限  | 含义           |
| --------- | --- | ------------ |
| 7 = 4+2+1 | rwx | 读写执行         |
| 6 = 4+2   | rw- | 读写（文件常用）     |
| 5 = 4+1   | r-x | 读 + 执行（目录常用） |
| 4         | r-- | 只读           |

- `chmod 755` →目录通用，网站文件夹
- `chmod 644` → 普通文件，网页文件
- `chmod 777` → 所有用户完全读写执行，**尽量不要随便用**
- `chmod 600` → 配置文件常用
