# 一、什么是Docker

**Docker 是一个容器化平台**，可以把应用程序连同它的**代码、运行环境、依赖、配置**一起打包成一个独立的**容器**，实现 “一次打包，到处运行”。

# 二、特点

 1. **轻量**：容器**共享宿主机内核**，不需要虚拟机那样完整操作系统镜像；镜像体积很小（MB 级别），启动快、占用资源低。
 2. **隔离性**：容器之间、容器与宿主机之间相互隔离，互不干扰。
 3. **可移植**：镜像可打包导出、上传镜像仓库（Docker Hub / 私有仓库），在任意安装 Docker 的机器拉取运行，让开发、测试、生产环境保持一致
 4. **版本化**：支持镜像版本管理，方便回滚。
 5. **分层镜像**：镜像采用**分层存储**，修改只新增层，复用已有层，节省空间、加速传输；

# 三、关键概念

|          | 镜像（Image）                  | 容器（Container） | 卷（Volume）                 |     |
| -------- | -------------------------- | ------------- | ------------------------- | --- |
| **定义**   | 只读模板                       | 镜像的运行实例       | 数据持久化的存储空间                |     |
| **生命周期** | 常驻，可复用、可分发                 | 创建→运行→停止→删除   | 独立于容器，不随容器删除              |     |
| **是否可写** | 只读，修改需重建新层                 | 可读写（运行时的临时数据） | 可读写，数据持久保存                |     |
| **产生方式** | Dockerfile build / 仓库 pull | 镜像 run        | docker volume create / 挂载 |     |
| **数量关系** | 一个镜像可创建多个容器                | 一个容器可挂载多个卷    | 一个卷可被多个容器共享               |     |
| **类比**   | 类（class）                   | 对象（instance）  | 外接硬盘                      |     |
其他：
- **Dockerfile**：文本文件，**声明式定义镜像怎么构建**（`docker build` 根据它打包成镜像）
- **仓库（Registry）**：存放镜像的地方
- **镜像库（Repository）**：存放一个镜像的不同版本

# 四、常见操作

## 常见查询命令

```bash
# 查看帮助 
docker --help

# 列出本地镜像 
docker images

# 查看正在运行容器 
docker ps 
# 查看所有容器（包含停止的） 
docker ps -a
# 查看容器详细信息（IP、挂载等） 
docker inspect 容器ID
# 查看容器日志 
docker logs 容器ID

# 列出数据卷 
docker volume ls
# 查看卷详情 
docker volume inspect 卷名
```

## 运行容器

`docker run`命令可以附带一系列参数，通常有这些内容需要考虑：
	1. 基础：**容器名称**，**端口映射**，**指定用户**
	2. **数据持久化**
	3. **网络**
	4. **资源限制**：最大内存，CPU核数
	5. **环境变量设置**
	6. **容器启停策略**
