
# 债券公平价格（Fair Price）

债券公平价格就是债券未来所有现金流，按合适的折现率折现到今天的现值之和。
> 债券未来拿到的钱，现在值多少钱

**按年付息债券**        $P = \sum_{t=1}^{n}\frac{C}{(1+r)^t}+\frac{F}{(1+r)^n}$

- C：每期利息 = 面值 F × 票面利率
- F：债券面值（到期还给你的本金，绝大多数债券面值 = 100）
- r：市场收益率（到期收益率）
- n：剩余付息期数

# YTM，到期收益率

$P=\sum_{t=1}^{n}\frac{C}{(1+YTM)^t}+\frac{F}{(1+YTM)^n}$

- P：债券当前市价
- C：每期利息
- F：债券面值
- n：剩余付息期数
