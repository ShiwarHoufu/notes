
# [和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 _该数组中和为 `k` 的子数组的个数_ 。
子数组是数组中元素的连续非空序列。

- 示例 1：
**输入**：nums = [1,1,1], k = 2
**输出**：2
- 示例 2：
**输入**：nums = [1,2,3], k = 3
**输出**：2

## 1. 暴力枚举
```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        int count = 0; 
        int length = nums.length;

        for(int i = 0; i < length; ++i){
            int sum = 0;
            for(int j = i; j < length; ++j){
                sum += nums[j];
                if(sum == k) count++;
            }
        }
        return count;
    }
}
```

## 2. 前缀和 + HashMap

- $preSum[j] - preSum[i] = k$
- $preSum[i] = preSum[j] - k$

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, 1); // 关键初始化,用来处理从下标 0 开始就满足和为 k 的子数组
        int preSum = 0;
        int count = 0;

        for (int num : nums) {
            preSum += num;
            // 去找有没有 preSum - k 这个前缀和
            if (map.containsKey(preSum - k)) {
                count += map.get(preSum - k);
            }
            // 更新当前前缀和的出现次数
            map.put(preSum, map.getOrDefault(preSum, 0) + 1);
        }
        return count;
    }
}
```

# [最大子数组和](https://leetcode.cn/problems/maximum-subarray/)

给你一个整数数组 `nums` ，请你找出一个具有最大和的**连续子数组**（子数组最少包含一个元素），返回其最大和。

示例 1：
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
（连续子数组 [4,-1,2,1] 的和最大，为 6 ）

示例 2：
输入：nums = [1]
输出：1

示例 3：
输入：nums = [5,4,-1,7,8]
输出：23

## 1. 前缀比较
### 思路

n = presumA - presumB
要找到 n 的最大值，即要找到 最大的前缀和 和 最小的前缀和。
遍历数组时得到当前前缀和，并更新最小前缀和。
记录 当前前缀和 - 最小前缀和，与result比较，判断该是不是更大。

### 代码
```java
class Solution {
    public int maxSubArray(int[] nums) {
        //记录最小的前缀和, 和当前位置的前缀和
        int min_presum = 0; // 初始值不能为 nums[0]，因为子数组可能就是原数组
        int current_presum = 0;

        int result = nums[0];
        
        for(int num : nums){
            current_presum += num;
            if((current_presum - min_presum) > result){
                result = current_presum - min_presum;
            }
            if(current_presum < min_presum) {
                min_presum = current_presum;
            }
        }

        return result;
    }
}
```
