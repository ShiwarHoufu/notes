# 个人知识仓库

程序员个人学习仓库，按技术分类组织笔记。整理工作由 AI agent 依据 [AGENTS.md](AGENTS.md) 中的规范完成。

## 仓库结构

```
notes/
├── AGENTS.md            # agent 行为规范
├── raw/                 # 未分类原材料：不确定归属时先放这里
└── <技术分类>/
    ├── raw/             # 该分类的未整理原材料（文本、截图等）
    └── <主题>.md        # 整理后的笔记
```

## 设计理念

- **记理解，不记语法。** 语法和API细节随时可查、AI可即时复现，笔记只保留难以快速重建的内容：原理与机制、设计权衡、架构视角的框架理解、踩坑经验。纯参考性内容最多一行带过。
- **原材料与成品分离。** 原始材料放进 `raw/` 后保持原样不动，是否清理由所有者决定；整理后的规范笔记放在分类目录下。
- **Agent 驱动的整理流程。** 把材料丢进 `raw/`，agent负责扫描、判断归属、去重合并、按取舍原则筛选内容，完成后汇报结果。

## 使用方式

1. 将原材料（文本、截图等）放入对应分类的 `raw/`，不确定归属就放根目录 `raw/`。
2. 让 agent 按 `AGENTS.md` 整理，检查其汇报与产出。
