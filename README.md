# 个人知识仓库

程序员个人学习仓库，按技术分类组织笔记。整理工作可由由 AI agent 依据 [AGENTS.md](AGENTS.md) 中的规范完成。

## 仓库结构

```
notes/
├── AGENTS.md            # agent 行为规范
├── raw/                 # 未分类原材料：不确定归属时先放这里
└── <技术分类>/
    ├── raw/             # 该分类的未整理原材料（文本、截图等）
    └── <主题>.md        # 整理后的笔记
```

- **Agent 驱动的整理流程。** 把材料丢进 `raw/`，agent负责扫描、判断归属、去重合并、按取舍原则筛选内容，完成后汇报结果。

## 使用方式

1. 将原材料（文本、截图、手写笔记等）放入对应分类的 `raw/`，不确定归属就放上层 `raw/`。
2. 让 agent 按 `AGENTS.md` 整理，检查其汇报与产出。

> 实际上 AI 整理的笔记还是不尽人意。这种模式只是一个参考。本仓库大部分内容还是由本人完成。
