# 项目开发设计流程

立项阶段、设计阶段、开发阶段、测试阶段、上线阶段、运营阶段、总结阶段

# 立项阶段

1.
1. 项目提出：基本方案
2. 需求讨论：会议纪要
3. 可行性分析：MRD、可行性报告
4. 立项启动：立项申请表

2.
基本方案：要做什么，为什么做，作用和价值
- 公司业务
- 核心业务的核心流程
- 前台，后台
- 好处有哪些

# 可行性分析

1.主要内容：**市场需求**，资源供应，功能规模，开发技术，设备选型，**环境影响**，资金筹备，**盈利能力**
2.市场环境对产品规划的影响：市场、用户、竞品
3.市场环境分析：1.市场调研  2.市场分析（目标市场及现状、市场趋势、问题，机会和壁垒）
4.用户分析：目标用户，用户画像，用户场景，用户需求总结
5.竞品分析：竞品战略，用户定位，产品功能对比，优缺点分析，竞品分析结论
6.市场信息查询参考平台

# 产品规划

如何规划：产品定位，目标用户，核心业务，主要功能，产品结构，版本规划

# 立项评审

1.立项说明书结构；产品概述，可行性分析，产品规划
2.评审议会流程：
1. 预约会议
2. 会前准备
3. 会议过程
4. 会后跟踪
3.立项申请表
