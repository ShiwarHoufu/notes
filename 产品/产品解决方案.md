
# 需求分析

1.需求分析的方法：Y模型（用户需求、目标动机、产品功能、人性）
2.人性七宗罪：
1. 傲慢（自大，自己拥有比别人多） -->  设计思路 -->  产品方案
2. 妒忌（别人拥有的比我多） 
3. 愤怒（妒忌到极点）
4. 懒惰（休息，享受）
5. 贪婪（想要更多）
6. 饕餮
7. 色欲
3.多体验产品
# 功能优先级划分

1.kano模型：具备程度、用户满意度
2.怎么得到kano模型：设计问卷、功能属性评定、根据属性象限区分优先级

# 功能价值

1.性价比 = 功能实际价值/功能实现成本
2.实际价值的判断：
1. 范围价值：潜在用户数 * 单用户价值
2. 频次价值：需求频次 * 单次价值
3. 时间价值：持续时间 * 单位价值
3.成本评估：人，天，每人每天多少钱，延期风险

# 用户体验

1.影响因素：使用者的状态、系统性能、环境
2.类别：感官、交互、情感
3.五要素：表现层、框架层、结构层、范围层、战略层
4.设计目标：有用、易用、友好、容错、吸引力、品牌
