# 核心用户

1.为什么要抓住核心用户
2.什么是目标客户、潜在客户、种子客户、核心客户
3.核心用户的特征（怎么区分、如何描述核心客户）：供需关系、人口统计学、熟悉程度、业务场景细分。
4.如何抓住核心用户：
1. 诱导式（面子、蹭热度、心理）、
2. 捆绑式（低价）；
3. 享受型（看重服务，超预期服务）；
4. 网络型（建立社交关系，实现口碑传播，注重大用户量）；
5. 股东型（筛选优质客户，打造利益共同体）

# 场景化分析

1.场景五要素：用户、地点、时间、行为、目的
2.怎么做场景化分析：列举场景要素、组合构建场景、预判发现需求
3.怎么预判：组成动作、用户认知流程、产品使用流程
4.场景化分析的应用：洞察问题、理解用户、带来超预期体验

# 需求的收集与辨别

1.马斯洛需求理论：生理需求、安全需求、爱与归属、尊重需求、自我实现
2.怎么收集：
1. 用户：望闻问切（观察、用户反馈、调查、切身感受）
2. 事情：因（业务分析、文献分析、头脑风暴）；果（竞品分析、数据分析）
3.一手需求，二手需求
4.辨别需求：真实、强烈（价值、风险、人群规模）、频率   ---->  ”四象限辨别“
