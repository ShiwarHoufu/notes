# 一、介绍
## 什么是事务（Transaction）

事务是一组操作的集合，是一个**不可分割**的工作单位，**要么全部执行成功，要么全部失败回滚**，不会出现只有一部分操作成功的中间状态。

## ACID

1. **Atomicity 原子性** 事务是最小单元，不可拆分，全成功或全失败。
2. **Consistency 一致性** 事务完成时，所有数据状态一致。
3. **Isolation 隔离性** 多个事务并发执行，互相之间隔离。（数据库系统提供的隔离机制）
4. **Durability 持久性** 事务一旦提交成功，数据库中数据的改变是永久的。

## 事务的基本控制

```sql
-- 开启事务 
START TRANSACTION; 
-- 提交事务：永久生效 
COMMIT; 
-- 回滚事务：撤销这一轮所有操作
ROLLBACK;
```
> 会触发隐式提交（implicit commit）:**（执行前提交当前事务）**
- DDL：`CREATE / ALTER / DROP / TRUNCATE / RENAME`
- 库操作：`CREATE DATABASE`
- 权限：`GRANT / REVOKE`
- 管理语句：`SET PASSWORD`
