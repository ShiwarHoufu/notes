# MySQL 数据类型

## 1. 数值类型

| 类型 | 大小(byte) | 有符号 SIGNED 范围 | 无符号 UNSIGNED 范围 | 描述 |
| --- | --- | --- | --- | --- |
| tinyint | 1 | (-128, 127) | (0, 255) | 小整数值 |
| smallint | 2 | (-32768, 32767) | (0, 65535) | 大整数值 |
| mediumint | 3 | (-8388608, 8388607) | (0, 16777215) | 大整数值 |
| int | 4 | (-2147483648, 2147483647) | (0, 4294967295) | 大整数值 |
| bigint | 8 | (-2^63, 2^63-1) | (0, 2^64-1) | 极大整数值 |
| float | 4 | (-3.4E+38, 3.4E+38) | 0 和 (1.17E-38, 3.4E+38) | 单精度浮点数值 |
| double | 8 | (-1.8E+308, 1.8E+308) | 0 和 (2.23E-308, 1.8E+308) | 双精度浮点数值 |
| decimal | | | | 小数值（**精度更高**） |

- 浮点型的无符号范围不是一个连续区间，写法是 **`0` 和 `(最小正数, 最大正数)`** 两段。

> `float(5,2)`、`double(5,2)`、`decimal(5,2)`：**5 表示整个数字的长度，2 表示小数位的个数**。

## 2. 日期时间类型

| 类型 | 大小(byte) | 范围 | 格式 | 描述 |
| --- | --- | --- | --- | --- |
| date | 3 | 1000-01-01 至 9999-12-31 | YYYY-MM-DD | 日期值 |
| time | 3 | -838:59:59 至 838:59:59 | HH:MM:SS | 时间值或**持续时间** |
| year | 1 | 1901 至 2155 | YYYY | 年份值 |
| datetime | 8 | 1000-01-01 00:00:00 至 9999-12-31 23:59:59 | YYYY-MM-DD HH:MM:SS | 混合日期和时间值 |
| timestamp | 4 | 1970-01-01 00:00:01 至 2038-01-19 03:14:07 | YYYY-MM-DD HH:MM:SS | 混合日期和时间值，**时间戳** |

- `time` 不只是「一天中的某个时刻」，也可用来表示**持续时长**。
- `datetime` 与 `timestamp` 都是「日期+时间」，差异在存储与范围：`timestamp` 只用 **4 字节**（datetime 8 字节），代价是范围被截断在 **2038-01-19** 之前。
