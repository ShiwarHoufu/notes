# 介绍

Mockito 是 Java 生态最主流的 **Mock 测试框架**，配合 JUnit 做单元测试。

## **解决的问题**：

- 被测类依赖 DAO，一跑测试就要连数据库，又慢还可能脏数据；
- 依赖第三方接口，不稳定、有费用；
- 依赖类还没开发完，无法测试。

## **核心概念**：

1. **Mock 对象**：运行时动态生成的代理子类（Byte Buddy 字节码生成），用来替代外部依赖。
2. **Stub（打桩）**：`when(对象.方法()).thenReturn(值)`，指定 mock 方法调用时返回什么数据，也可以抛异常。
3. **Verify（验证）**：`verify(mock对象, times(1)).方法()`，校验被测代码**行为**：方法是否调用、调用次数、参数是否正确。
4. **Spy**：监视真实对象，**默认执行原方法逻辑**，可以对部分方法打桩；和 Mock 不同，Mock 默认所有方法都空返回。
