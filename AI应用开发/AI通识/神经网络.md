
# 网络结构

- 输入层：原始特征
- 隐藏层：中间特征提取，深度网络就是多层隐藏层
- 输出层：预测结果（回归 / 二分类 / 多分类）

## 神经元

**神经网络最基础的计算单元**
>灵感来自人脑生物神经元，但只是一个简单的数学模型，不要和真实脑细胞等同。

公式：
$$y = \sigma\left( \sum_{i=1}^n w_i x_i + b \right)$$
1. $x_1,x_2,\dots,x_n$：**输入input**，别的神经元传过来的数据 / 特征
2. $w_1,w_2,\dots,w_n$：**权重 weight**，代表这个输入有多重要
3. $b$：**偏置 bias**，用来整体平移，控制激活的难易
4. $\sum w_i x_i + b$：**净输入（线性组合）**
5. $\sigma()$：**激活函数**，给神经元引入非线性（如果没有它，再多层网络也等价于单层线性模型）
6. $y$：这个神经元的输出，传给下一层

# 一次训练迭代

**前向传播**（Forward Propagation）：
- 输入特征沿着网络结构，经过每一层的线性变换与激活函数，最终输出预测结果。
**计算损失**：
- 计算出预测值与真实标签之间的**损失（误差）**
**反向传播**（Back Propagation）：
- 以损失为起点，利用**微积分链式法则**，反向逐层计算每一个参数的梯度。
> 算出每个参数该往哪个方向调、调多少，能让损失下降。
